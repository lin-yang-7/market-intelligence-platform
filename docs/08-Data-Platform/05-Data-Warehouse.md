# Data Warehouse

Version: 1.0

Status: Approved

------------------------------------------------------------------------

# 1. Purpose

Defines analytical data warehouse architecture.

------------------------------------------------------------------------

# 2. Warehouse Role

Provides:

-   Business analysis
-   Model training data
-   Historical research

------------------------------------------------------------------------

# 3. Layer Architecture

    Raw Data Layer

    ↓

    Detail Data Layer

    ↓

    Feature Layer

    ↓

    Analysis Layer

------------------------------------------------------------------------

# 4. Data Layers

## Raw Layer

Stores original events.

## Detail Layer

Stores cleaned data.

## Feature Layer

Stores calculated features.

## Analysis Layer

Stores business metrics.

------------------------------------------------------------------------
