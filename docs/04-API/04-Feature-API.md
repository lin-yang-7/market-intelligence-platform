# Feature API

Version: 1.0

Status: Approved

------------------------------------------------------------------------

# 1. Purpose

This document defines the Feature API of the Market Intelligence
Platform.

Feature API provides access to quantitative features generated by the
Feature Engine and stored in the Feature Store.

The API supports:

-   Feature discovery
-   Current feature values
-   Historical feature data
-   Feature metadata
-   Model input data

------------------------------------------------------------------------

# 2. API Base Path

    /v1/feature

------------------------------------------------------------------------

# 3. Feature Concepts

A Feature represents a quantitative market signal component.

Examples:

Technical:

-   RSI
-   MACD
-   Moving Average

Market:

-   Volume Change
-   Volatility
-   Funding Rate

Derivative:

-   Open Interest Change
-   Long Short Ratio

------------------------------------------------------------------------

# 4. Feature List API

## Endpoint

    GET /feature/list

Purpose:

Get available features.

------------------------------------------------------------------------

## Response

``` json
{
 "code":0,
 "data":[
  {
   "name":"rsi",
   "category":"technical",
   "version":"1.0"
  }
 ]
}
```

------------------------------------------------------------------------

# 5. Feature Metadata API

## Endpoint

    GET /feature/meta

Purpose:

Get feature definition.

------------------------------------------------------------------------

## Parameters

  Parameter   Required
  ----------- ----------
  feature     Yes

------------------------------------------------------------------------

## Response

``` json
{
 "name":"volume_ratio",
 "description":"Volume change ratio",
 "type":"float",
 "updateInterval":"1m"
}
```

------------------------------------------------------------------------

# 6. Current Feature API

## Endpoint

    GET /feature/current

Purpose:

Get latest feature value.

------------------------------------------------------------------------

## Request

Parameters:

  Parameter   Required
  ----------- ----------
  symbol      Yes
  feature     Yes

------------------------------------------------------------------------

## Response

``` json
{
 "code":0,
 "data":{
  "symbol":"BTCUSDT",
  "feature":"rsi",
  "value":65.5,
  "timestamp":1700000000000
 }
}
```

------------------------------------------------------------------------

# 7. Batch Feature API

## Endpoint

    GET /feature/batch

Purpose:

Get multiple features for one symbol.

------------------------------------------------------------------------

## Request

Example:

    symbol=BTCUSDT

    features=rsi,macd,volume_ratio

------------------------------------------------------------------------

## Response

``` json
{
 "symbol":"BTCUSDT",
 "features":{
  "rsi":65,
  "macd":1.2,
  "volume_ratio":2.5
 }
}
```

------------------------------------------------------------------------

# 8. Historical Feature API

## Endpoint

    GET /feature/history

Purpose:

Query historical feature values.

------------------------------------------------------------------------

## Parameters

  Parameter   Required
  ----------- ----------
  symbol      Yes
  feature     Yes
  startTime   No
  endTime     No
  limit       No

------------------------------------------------------------------------

## Response

``` json
{
 "data":[
  {
   "timestamp":1700000000000,
   "value":60
  }
 ]
}
```

------------------------------------------------------------------------

# 9. Feature Ranking API

## Endpoint

    GET /feature/ranking

Purpose:

Rank symbols by feature value.

------------------------------------------------------------------------

## Example

Request:

    feature=volume_ratio

Response:

``` json
{
 "data":[
  {
   "symbol":"BTCUSDT",
   "value":3.2,
   "rank":1
  }
 ]
}
```

------------------------------------------------------------------------

# 10. Feature Version

Every feature contains:

-   Name
-   Version
-   Calculation logic
-   Update frequency

Example:

    rsi:v1
    volume_ratio:v2

------------------------------------------------------------------------

# 11. Data Source

Feature generation flow:

    Market Data

    ↓

    Feature Engine

    ↓

    Feature Store

    ↓

    Feature API

------------------------------------------------------------------------

# 12. Rate Limits

Limits depend on:

-   Subscription plan
-   Feature complexity
-   Request frequency

------------------------------------------------------------------------

# 13. Error Codes

  Code   Meaning
  ------ ---------------------
  3001   Feature not found
  3002   Invalid symbol
  3003   Feature unavailable

# 15. Compliance

Every Feature API must define:

-   Feature name
-   Version
-   Formula
