# Coding Standards

Version: 1.0

## 1. Purpose

Defines coding conventions.

## 2. General Rules

Code must be:

-   Readable
-   Maintainable
-   Tested

## 3. Backend

Follow:

-   Layer architecture
-   Type annotations
-   Error handling

## 4. Frontend

Follow:

-   Component reuse
-   TypeScript types
-   Clear state ownership

## 5. Documentation

Important modules require comments.
