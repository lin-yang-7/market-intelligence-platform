# Signal API

Version: 1.0

Status: Approved

------------------------------------------------------------------------

# 1. Purpose

This document defines the Signal API of the Market Intelligence
Platform.

Signal API provides intelligent market event data generated by the
Signal Engine.

Core scenarios:

-   Real-time trading signals
-   Long inflow alerts
-   Market opportunity discovery
-   Signal explanation
-   Historical signal analysis

------------------------------------------------------------------------

# 2. API Base Path

    /v1/signal

------------------------------------------------------------------------

# 3. Signal Concept

A signal is generated from:

-   Market data
-   Quantitative features
-   Ranking score
-   Rule engine
-   AI model

Flow:

    Market Data

    ↓

    Feature Engine

    ↓

    Score Engine

    ↓

    Signal Engine

    ↓

    Signal API

------------------------------------------------------------------------

# 4. Signal Types

Supported:

  Type         Description
  ------------ ----------------------------
  longInflow   Long capital inflow signal
  breakout     Price breakout signal
  momentum     Momentum signal
  reversal     Trend reversal signal
  volatility   Volatility signal

------------------------------------------------------------------------

# 5. Current Signal API

## Endpoint

    GET /signal/current

Purpose:

Get active market signals.

------------------------------------------------------------------------

## Parameters

  Parameter   Required
  ----------- ----------
  symbol      No
  type        No
  limit       No

------------------------------------------------------------------------

## Response

``` json
{
 "code":0,
 "data":[
  {
   "signalId":"sig_001",
   "symbol":"BTCUSDT",
   "type":"longInflow",
   "score":95,
   "confidence":0.92
  }
 ]
}
```

------------------------------------------------------------------------

# 6. Long Inflow Signal API

## Endpoint

    GET /signal/longInflow

Purpose:

Get long capital inflow alerts.

------------------------------------------------------------------------

## Response

``` json
{
 "symbol":"BTCUSDT",
 "type":"longInflow",
 "score":96,
 "inflow":15000000,
 "confidence":0.94,
 "reasons":[
  "large_buy_volume",
  "volume_breakout",
  "positive_momentum"
 ]
}
```

------------------------------------------------------------------------

# 7. Signal Detail API

## Endpoint

    GET /signal/detail

Purpose:

Get complete signal explanation.

------------------------------------------------------------------------

## Request

    signalId=sig_001

------------------------------------------------------------------------

## Response

``` json
{
 "signalId":"sig_001",
 "symbol":"BTCUSDT",
 "score":95,
 "factors":{
  "inflow":92,
  "volume":88,
  "momentum":90
 },
 "explanation":"Strong capital inflow detected"
}
```

------------------------------------------------------------------------

# 8. Signal History API

## Endpoint

    GET /signal/history

Purpose:

Query historical signals.

------------------------------------------------------------------------

## Parameters

  Parameter   Required
  ----------- ----------
  symbol      Yes
  startTime   No
  endTime     No
  limit       No

------------------------------------------------------------------------

# 9. Signal Fields

Common fields:

  Field        Description
  ------------ -------------------
  signalId     Signal identifier
  symbol       Trading pair
  type         Signal type
  score        Signal score
  confidence   Confidence
  reasons      Trigger reasons
  timestamp    Creation time

------------------------------------------------------------------------

# 10. Signal Score

Score range:

    0 - 100

Example:

  Score      Meaning
  ---------- ---------------
  90-100     Strong signal
  70-90      Medium signal
  Below 70   Weak signal

------------------------------------------------------------------------
