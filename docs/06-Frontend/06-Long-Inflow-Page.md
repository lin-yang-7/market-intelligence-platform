# Long Inflow Page Design

Version: 1.0

## 1. Purpose

Defines the core intelligent coin selection page similar to professional
market intelligence platforms.

## 2. Page Goal

Provide:

-   Long capital inflow discovery
-   Real-time ranking
-   Signal explanation
-   Opportunity monitoring

## 3. Page Layout

    Long Inflow Page

    ├── Filter Panel
    ├── Ranking Table
    ├── Coin Detail
    ├── Score Analysis
    └── Signal Timeline

## 4. Ranking Table

Fields:

-   Symbol
-   Price
-   Inflow
-   Score
-   Confidence
-   Rank
-   Update Time

## 5. Filter

Supports:

-   Timeframe
-   Exchange
-   Minimum Score
-   Volume
-   Confidence

## 6. Detail Panel

Displays:

-   Feature contribution
-   Score factors
-   Historical trend
-   Signal reasons

## 7. Real-time Update

Uses:

-   ranking.updated
-   signal.created

## 8. Compliance

All data fields must map to backend APIs.
