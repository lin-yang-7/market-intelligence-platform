# Market Intelligence Platform

AI-powered crypto market intelligence platform.

## Overview

This project builds an intelligent coin selection system similar to
professional market intelligence platforms.

Core capabilities:

-   Real-time market monitoring
-   Long Inflow detection
-   Intelligent ranking
-   AI scoring
-   Signal generation
-   External API services

------------------------------------------------------------------------
