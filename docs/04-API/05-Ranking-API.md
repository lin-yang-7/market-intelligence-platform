# Ranking API

Version: 1.0

Status: Approved

------------------------------------------------------------------------

# 1. Purpose

This document defines the Ranking API of the Market Intelligence
Platform.

Ranking API provides intelligent market ranking capabilities similar to
professional market intelligence platforms.

Core scenarios:

-   Intelligent coin selection
-   Long inflow ranking
-   Momentum ranking
-   Volume ranking
-   Market strength analysis

------------------------------------------------------------------------

# 2. API Base Path

    /v1/ranking

------------------------------------------------------------------------

# 3. Ranking Concept

A ranking result is generated by combining:

-   Market data
-   Quantitative features
-   Rule engine
-   Scoring engine
-   AI model (optional)

Flow:

    Market Data

    ↓

    Feature Engine

    ↓

    Score Engine

    ↓

    Ranking API

------------------------------------------------------------------------

# 4. Ranking Types

Supported rankings:

  Type         Description
  ------------ ---------------------------
  overall      Comprehensive ranking
  long         Long opportunity ranking
  short        Short opportunity ranking
  momentum     Momentum ranking
  volume       Volume activity ranking
  volatility   Volatility ranking

------------------------------------------------------------------------

# 5. Overall Ranking API

## Endpoint

    GET /ranking/overall

Purpose:

Get comprehensive market ranking.

------------------------------------------------------------------------

## Request Parameters

  Parameter   Required
  ----------- ----------
  exchange    No
  limit       No

------------------------------------------------------------------------

## Response

``` json
{
 "code":0,
 "data":[
  {
   "rank":1,
   "symbol":"BTCUSDT",
   "score":92.5,
   "change24h":3.2
  }
 ]
}
```

------------------------------------------------------------------------

# 6. Long Inflow Ranking API

## Endpoint

    GET /ranking/longInflow

Purpose:

Identify coins with strong long-side capital inflow.

This API aligns with the intelligent coin selection scenario.

------------------------------------------------------------------------

## Request Parameters

  Parameter   Required
  ----------- ----------
  exchange    No
  timeframe   No
  limit       No

Examples:

    5m

    15m

    1h

    4h

    1d

------------------------------------------------------------------------

## Response

``` json
{
 "code":0,
 "data":[
  {
   "rank":1,
   "symbol":"BTCUSDT",
   "score":95.2,
   "inflow":12000000,
   "volumeChange":35.5,
   "priceChange":5.2,
   "confidence":0.91
  }
 ]
}
```

------------------------------------------------------------------------

# 8. Momentum Ranking API

## Endpoint

    GET /ranking/momentum

Purpose:

Rank coins by momentum strength.

Factors:

-   Price trend
-   Volume
-   Volatility
-   Market strength

------------------------------------------------------------------------

# 9. Volume Ranking API

## Endpoint

    GET /ranking/volume

Purpose:

Find high activity assets.

Metrics:

-   Volume
-   Volume change
-   Trading frequency

------------------------------------------------------------------------

# 10. Score Detail API

## Endpoint

    GET /ranking/detail

Purpose:

Explain ranking score.

------------------------------------------------------------------------

## Request

    symbol=BTCUSDT

------------------------------------------------------------------------

## Response

``` json
{
 "symbol":"BTCUSDT",
 "score":95,
 "factors":{
  "inflow":90,
  "volume":85,
  "momentum":92
 }
}
```

------------------------------------------------------------------------

# 11. Ranking Fields

Common fields:

  Field        Description
  ------------ ------------------
  rank         Ranking position
  symbol       Trading pair
  score        Composite score
  confidence   Confidence level
  timestamp    Update time
